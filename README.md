# 📖 Overview

Movixa is a modern front-end web application that allows users to discover animated movies in an attractive and responsive interface.

The website provides categorized movie collections, trending movies, latest releases, search functionality, detailed movie pages, and smooth interactive animations.

The entire project is built using modern front-end technologies with dynamic data loaded from JSON APIs.
